## Русский

W-Fix v3.0 — стабильный выпуск Remote Repair Center для доменных Windows 10/11. Он сохраняет 12 локальных фиксеров и добавляет удалённый preflight, инвентаризацию, доказательную диагностику, планирование реального ремонта, снимки, проверку результата, rollback, пакетное выполнение и обезличенные support bundles.

Стабильный тег разрешено создавать только после лабораторной проверки Windows 10/11 и закрытия критических дефектов текущей beta. Актуальные требования и ограничения описаны в `docs/remote-center.md`.

## English

W-Fix v3.0 is the stable Remote Repair Center release for domain-joined Windows 10/11 machines. It retains all 12 local fixers and adds remote preflight, inventory, evidence-based diagnostics, real repair planning, snapshots, verification, rollback, batch execution, and sanitized support bundles.

The stable tag may be created only after Windows 10/11 lab validation and closure of all critical beta defects. Current requirements and limitations are documented in `docs/remote-center.md`.
